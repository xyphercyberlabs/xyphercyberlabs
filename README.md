## Mirko Daether · Xypher Cyber Labs

Ich baue Automatisierungen für kleine Betriebe in Mecklenburg-Vorpommern —
selbst gehostet, DSGVO-konform, zum Festpreis.

### Was ich mache

- Anbindungen zwischen Programmen, die nicht miteinander reden: Webhook, API, Datei, Postfach
- Datenübergaben zwischen CRM, ERP, Buchhaltung und Kalender
- KI-Schritte dort, wo sie Zeit sparen — mit lokalen Modellen, wenn die Daten es verlangen

### Wie ich baue

- **Fehlerbenachrichtigung** — geht etwas schief, erfährt es der Betrieb, nicht dessen Kunde
- **Wiederholungslogik** statt stillem Abbruch, wenn ein fremder Dienst kurz weg ist
- **Keine Doppelten** — jeder Vorgang wird genau einmal verarbeitet, auch bei abgebrochenen Läufen
- **Schriftliche Übergabe** — Aufbau, Zugänge, Grenzen, Wartung

### Werkzeuge

n8n (selbst gehostet) · PostgreSQL · Docker · Ollama für lokale Modelle
